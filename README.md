# 外滩七号建筑数字影像档案
《一江一河滨水公共空间更新比较研究》高中环境设计研究项目交互原型。

## 本地运行
直接使用浏览器打开 `index.html` 即可，无需安装依赖。
也可在项目目录执行：
```sh
python3 -m http.server 8000
```
随后浏览器访问 http://localhost:8000 。停止服务按 Ctrl+C。

## 文件
- index.html：中文展陈内容与页面结构
- style.css：响应式布局、博物馆配色、减少动画偏好支持
- app.js：立面热点、时间滑块、对比切换、影像筛选/放大、三题观察游戏
- assets/facade.svg：项目原创教学占位图，不是外滩七号真实立面

## 内容与素材约束
本版没有可靠授权的实景图片，因此使用原创 SVG 示意，并在页面明确标注。不可将示意图作为外滩七号的建筑形态、层数、比例或装饰证据。历史年代、用途、风格等未核实信息均标记待考证；时间线展示研究阶段，不冒充历史年表。比较表为调研框架，研究总结为分析建议。
后续替换图片时，添加作者、拍摄日期、来源链接、授权协议与图注；核实每条历史事实后再更新页面。不得将政府门户检索入口当作已查阅的证据。

## 手动验收
依次检查导航；四个立面热点；滑块及四个历史节点；两种比较对象；影像筛选及图片弹窗（Esc 关闭）；游戏按 03、01、02 完成，错误点击不加分，重新开始归零；手机宽度下检查布局及表格横向滚动。
